# Sistema para la gestión de prácticas profesionales
Sistema que permite llevar un control de horas de prácticas profesionales realizadas por los estudiantes de la Universidad de El Salvador.

Los objetivos principales son:
- Registrar expedientes
- Dar seguimiento al avance mensual
- Permitir la carga de informes
- Generar reportes

## Ejecutar proyecto
```powershell
npm run build
mvn clean instal
mvn spring-boot:run
```
